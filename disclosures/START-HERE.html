Local preview

Double-click START-WINDOWS.cmd (Python 3.12 required), or run:

py -3.12 app/serve.py

Then open http://127.0.0.1:8080. The HTTP server is required to load data shards; do not open docs/index.html directly.

Update GitHub Pages

Existing installation: read UPGRADE-EXISTING.md and preserve docs/data/. New installation: read DEPLOY-GITHUB.md. Upgrade your independent Filing-Flows-Disclosure-Lab repository and replace its workflow with automation/update-and-deploy.yml through GitHub's editor.

The ZIP has no dot-prefixed paths. Upload in batches if using the browser. The SEC contact remains Eurika · eurikamonica@gmail.com.
