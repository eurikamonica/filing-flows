# 因子研究笔记库

这是一个长期积累的研究笔记库，记录股票投资因子（也叫异象）、提出和检验它们的学术论文，以及构建、检验因子用到的分析方法。笔记用简体中文写；论文标题、作者名、因子名和公式保留原文。

研究重点是美股。某个因子或方法在 A 股也有检验证据时，作为补充单列一节。

## 目录结构

| 位置 | 内容 |
|---|---|
| [INDEX.md](INDEX.md) | 总目录：每篇笔记一行，写明加入日期、类型、标题、标签和一句话结论。想知道某个题目写过没有，先看这里。 |
| [QUEUE.md](QUEUE.md) | 待写清单：已经发现、还没写的题目，以及为什么值得写。 |
| `factors/` | 因子笔记：一个因子或异象一篇。 |
| `papers/` | 论文笔记：一篇论文一篇，文件名为 `年份-第一作者姓-主题.md`。 |
| `methods/` | 方法笔记：实证资产定价方法（组合排序、Fama-MacBeth 回归、GRS 检验等），以及构建因子用到的财报分析方法（应计模型、杜邦分析、F-score 等）。 |
| `log/` | 运行日志：每次做了什么、查了哪些来源、还有哪些没解决的问题。 |

## 每类笔记的结构

- **因子笔记**：一句话结论 → 定义与构造 → 经济直觉 → 原始证据 → 复制与衰减 → 与其他因子的关系 → A股证据 → 数据与计算（需要哪些财报科目，在 10-K/10-Q 的什么位置，怎样避免前视偏差）→ 实施注意 → 参考文献。
- **论文笔记**：引用信息 → 研究问题 → 数据与样本 → 方法 → 主要发现 → 贡献与影响 → 批评与后续研究 → 与库内笔记的关系。
- **方法笔记**：是什么、何时用 → 步骤 → 公式 → 常见陷阱 → 一个小例子 → 参考文献。

## 写作规则

- 每个数字和每条引用都对照实际打开过的原始来源核实；核实不了的不写，或标注「未核实」。
- 用自己的话转述，不粘贴论文的摘要、段落、表格或图。
- 第一次出现的专业术语都要解释；数字用表格，公式用 LaTeX。
- 这里是研究和学习笔记，不是投资建议，不对个股给出买卖意见。

## 怎么更新

一个定时任务每天美东时间早上运行：先读总目录和待写清单，挑一个还没写过的题目，从原始论文和作者公开的数据中查证后写成笔记，再开一个 PR，由仓库的每小时 PR 任务合并。
