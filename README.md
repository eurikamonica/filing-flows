# holders-history (data only)

Each quarter of SEC Form 13F data sets read into holders per CUSIP (cache/periods), the data sets read (cache/sets.json)
and the files the video studio reads (public/: c/<TICKER>.json, m/<CIK>.json, i/<TICKER>.json for insiders from Forms 3/4/5 (cache/insiders), index.json, status.json),
kept by .github/workflows/holders-history.yml on main.
Force-pushed as a single commit on every run.
