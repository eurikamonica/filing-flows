## 基础因子与模型

- [ ] CAPM 与 beta 异象：因子模型的起点；低 beta 股票的实际收益高于 CAPM 的预测
- [ ] 规模因子（Banz 1981）：最早被记录的横截面异象之一，后来对它是否稳定争议很多
- [ ] 价值因子（Basu 1977；Rosenberg-Reid-Lanstein 1985；Fama-French 1993）：账面市值比直接来自资产负债表，和财报分析联系最紧
- [ ] 动量（Jegadeesh-Titman 1993；Carhart 1997）：过去的赢家继续跑赢；Carhart 把它加进了三因子模型
- [ ] 短期反转：上个月的赢家下个月倾向于跑输，和流动性、交易成本关系密切
- [ ] Fama-French 五因子模型（2015）：在三因子之外加入盈利能力（RMW）和投资（CMA）
- [ ] q 因子模型（Hou-Xue-Zhang 2015）：从企业投资的角度解释大量异象
- [ ] 特征还是协方差（Daniel-Titman 1997）：收益来自股票特征本身，还是来自对风险因子的暴露

## 财报（会计）类因子

- [ ] 应计异象（Sloan 1996）：利润里应计部分占比高的公司，后续股票收益偏低
- [ ] 毛利盈利能力（Novy-Marx 2013）：毛利除以总资产能预测收益，和价值因子互补
- [ ] Piotroski F-score（2000）：用 9 个财报信号在价值股里区分好坏公司
- [ ] 资产增长（Cooper-Gulen-Schill 2008）：总资产增长快的公司，后续收益偏低
- [ ] 净经营资产（Hirshleifer-Hou-Teoh-Zhang 2004）：资产负债表“臃肿”的公司容易被高估
- [ ] 盈余公告后漂移（Bernard-Thomas 1989）：股价对盈余意外的反应不完全，会继续漂移
- [ ] 质量减垃圾 QMJ（Asness-Frazzini-Pedersen 2019）：把盈利、增长、安全等质量特征合成一个因子
- [ ] 研发与无形资产：研发费用化使账面价值偏低，影响价值等因子的度量

## 风险与行为类

- [ ] 押注低 beta BAB（Frazzini-Pedersen 2014）：用杠杆约束解释低 beta 异象
- [ ] 特质波动率（Ang-Hodrick-Xing-Zhang 2006）：特质波动率高的股票后续收益偏低
- [ ] MAX / 彩票型股票（Bali-Cakici-Whitelaw 2011）：投资者偏好极端正收益，推高这类股票的价格
- [ ] 非流动性（Amihud 2002）：用价格冲击度量流动性，以及非流动性溢价
- [ ] 错误定价因子（Stambaugh-Yuan 2017）：把多个异象合成两个错误定价因子
